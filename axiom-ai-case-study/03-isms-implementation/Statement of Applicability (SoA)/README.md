## Statement of Applicability (SoA)

The Statement of Applicability (SoA) documents the applicability and implementation status of the ISO/IEC 27001:2022 Annex A controls within the Axiom AI Technologies ISMS.

### Contents

The SoA includes:

* All 93 ISO/IEC 27001:2022 Annex A controls
* Applicability determination and justification
* Control implementation status
* Related ISMS policies
* Related risks and findings
* Control ownership
* Evidence and reference fields
* Summary metrics by Annex A control domain

### Implementation Status

Controls are categorized using the following statuses:

* **Implemented** — The control is established within the modeled Axiom AI environment.
* **Partially Implemented** — The control is addressed in part, but identified gaps or remediation activities remain.
* **Planned** — The control is applicable but implementation evidence has not yet been established within the project.

### ISMS Integration

The SoA connects the major components of the Axiom AI ISMS project:

**Risk Assessment → Control Assessment → Policies → Statement of Applicability → Remediation & Continual Improvement**

This provides a traceable relationship between identified information security risks, applicable ISO 27001 controls, organizational policies, and implementation activities.

### Portfolio Disclaimer

This artifact is a fictional portfolio demonstration based on a modeled Axiom AI Technologies environment. It is intended to demonstrate practical GRC and ISO/IEC 27001 implementation skills and does not represent an actual certification assessment or independent audit.
